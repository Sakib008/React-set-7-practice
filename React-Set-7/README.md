# 🧰 Dev Box
Dev Box is a multifunctional React application that combines multiple mini-apps into a single platform. This project demonstrates practical use of state management, search and filter logic, math functions, and component reusability. Each mini-app is accessible through navigation links and provides a specific functionality.

## 🚀 Features
### 🌦 Weather App
- Switch between celcius

- Temperature, humidity, and condition display
### 💬 Quote Generator
- Random quote display on click

- Uses Math.random() for random selection

- Encouraging and motivational quotes

### 🛍 Products App
- Product listing with name, category, and price

- Search and filter functionality

- Select products by category or name

### 🎬 Movies App


- Search and filter based on year
- Simple, clean UI for discovery

## 🧠 Concepts Used
- 🔁 State Management using React hooks (useState, useEffect)

- 🧮 Math Functions for quote generation

- 🔍 Search & Filter logic for products and movies

- 🔗 Reusable Components for scalability

- 🌐 Routing with react-router-dom for navigation

## 🛠 Tech Stack
React.js

HTML5 & CSS3

JavaScript (ES6+)
